**DiscForge RU** — приложение с русскоязычным интерфейсом на Python и PySide6. Оно объединяет анализ видео, кодирование через FFmpeg и подготовку BDMV / ISO через tsMuxer в один рабочий процесс.

> **Альфа 0.2.0.** Добавлено экспериментальное дисковое меню BD-J: «Смотреть», главы и возврат в меню. Windows собирает ISO UDF 2.50 штатными средствами. Аппаратные испытания ещё не проведены; универсальная совместимость не заявляется.

Цель проекта — полноценная бесплатная альтернатива набору инструментов DVDFab. Текущий этап — Full HD Blu-ray Creator; копирование, конвертация дисков, UHD и файловые носители идут отдельными этапами в [плане развития](docs/PRODUCT_PLAN.md).

## Быстрый старт

### Требования

- **Windows 10/11** и **Python 3.11+**; macOS поддерживается экспериментально.
- Установленные отдельно **FFmpeg**, **ffprobe** и **tsMuxer**.
- Свободное место для промежуточного видео и итогового образа.

Внешние инструменты должны быть доступны в `PATH` или указаны в настройках приложения полными путями.

### Windows

```powershell
git clone https://github.com/maxliv234-star/DiscForge-RU.git
cd DiscForge-RU
.\start_windows.bat
```

Скрипт создаёт виртуальное окружение, устанавливает зависимости и запускает интерфейс. Для ручного запуска:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

### macOS

```bash
git clone https://github.com/maxliv234-star/DiscForge-RU.git
cd DiscForge-RU
bash start_macos.command
```

Подключение привода, запись готового ISO и сборка `.app` описаны в [руководстве macOS](docs/MACOS.md).

### Первый проект

1. Добавьте небольшой тестовый видеофайл и проверьте результат анализа.
2. Выделите фильм и выберите **звуковую дорожку** на вкладке **Подготовка**. Каждый фильм в очереди запоминает свой выбор; по умолчанию — первая дорожка.
3. На вкладке **Главы** задайте точки перехода.
4. На вкладке **Меню** задайте название и оформление; проверьте переходы кнопками пульта под предпросмотром.
5. Выберите **BD25**, **CPU x264** и выходную папку. Вкладка **Подготовка** содержит пути к инструментам.
6. Нажмите **Создать Blu-ray** и дождитесь завершения.
7. Проверьте результат в проигрывателе. На вкладке **Запись ISO** проверьте образ и откройте запись Windows; включите проверку записанного диска. Для первого физического теста используйте BD-RE.

Java на компьютере для создания меню не требуется: готовый Xlet входит в приложение. Для воспроизведения BD-J в VLC нужен совместимый Java runtime. На бытовом плеере используется его собственная среда BD-J.

## Командная строка

CLI работает без PySide6:

```powershell
py -3 cli.py probe "C:\Video\movie.mkv"
py -3 cli.py build "C:\Video\movie.mkv" --profile BD25 --output "D:\BluRay" --chapter 00:10:00 --chapter 00:30:00
```

Добавьте `--folder` для папки BDMV вместо ISO. Для выбора исходного звука в CLI используйте `--audio-index 1` (индексы начинаются с нуля и считаются только по аудиопотокам). В GUI выбор отдельный для каждого фильма и сохраняется в `.dfr.json`. Одновременно выводится только одна дорожка AC-3. GUI и CLI используют общее ядро и одинаковые ограничения.

Меню из CLI: добавьте `--menu-title "Мой фильм" --menu-theme cinema`. Этот режим требует зависимостей Qt из `requirements.txt`; остальные команды работают без Qt. ISO с меню сейчас создаётся на Windows, папка BDMV — также на других ОС.

## Ограничения

- Один видеофайл становится одним диском; общий диск с несколькими фильмами пока не поддерживается.
- Видеоряд приводится к 1080p / 23,976 fps; изменение частоты кадров может влиять на плавность.
- HDR-исходники блокируются до появления UHD-конвейера.
- Windows GUI передаёт проверенный образ системной программе записи. Интегрированный драйвер записи и отчёт об аппаратной сверке ещё не реализованы. macOS-утилита записывает ISO отдельно.
- Расчёт битрейта предварительный; фактический размер проверяется после сборки.
- Проверки BDMV и UDF являются структурными; соответствие всем требованиям Blu-ray и работа на конкретном плеере ими не подтверждаются.
- Обход DRM / AACS и загрузка фильмов не входят в возможности проекта.

Выходные файлы получают уникальные имена вместо перезаписи. Промежуточные данные удаляются после завершения или ошибки.

## Разработка

```powershell
py -3 -m unittest discover -s tests -v
.\build_exe_windows.bat
```

Windows-сборка: `dist\DiscForge_RU\DiscForge_RU.exe`. FFmpeg и tsMuxer в дистрибутив не включены.

| Путь | Назначение |
| :--- | :--- |
| `main.py` | Интерфейс, очередь обработки и редактор глав |
| `cli.py` | Командная строка |
| `core.py` | Анализ → кодирование → tsMuxer → BDMV / ISO |
| `disc_menu.py`, `menu_editor.py`, `bdj/` | Дисковое меню, общий рендерер и исходник Xlet |
| `windows_iso.py`, `tools/windows_iso.ps1` | UDF 2.50 через IMAPI2FS без записи на привод |
| `image_tools.py` | Проверка ISO и открытие записи Windows |
| `bdmv_preflight.py` | Структурная проверка BDMV |
| `macos_burn.py` | Запись готового ISO на macOS |
| `settings.py` | Локальные настройки |
| `tests/` | Автоматические проверки |
| `.github/workflows/` | Тесты и сборки Windows / macOS |
