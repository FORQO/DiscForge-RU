# Аудиодорожки в 1.2

После анализа во вкладке «Аудио» показаны все обнаруженные звуковые потоки. Галочки относятся к выбранному слева фильму. По умолчанию используется первая дорожка; пустой выбор создаёт диск без звука. Предел — 32 дорожки, но ёмкость и суммарный битрейт могут потребовать меньшего числа или перекодирования.

| Режим | Видео | Выбранный звук |
|---|---|---|
| Авто | По результатам анализа | Копирование подходящего AC-3, преобразование остальных |
| Без перекодирования | Копирование | Только проверенный совместимый AC-3; иначе отказ |
| Копировать видео | Копирование | Совместимый AC-3 сохраняется, остальное преобразуется |
| Перекодировать | H.264 1080p23.976 | Все выбранные дорожки в AC-3 48 кГц, 640 кбит/с, 2 или до 6 каналов |

Для копирования AC-3 проверяются 48 кГц, до 640 кбит/с, 1–6 каналов, пакеты, непрерывность и согласованность временных меток. Неподходящий звук не запрещает копировать совместимое видео в автоматическом режиме. Анализ всех дорожек выполняется за один проход ffprobe; изменение галочек не сканирует фильм заново.

Каждая выбранная дорожка извлекается по **глобальному индексу потока**, а не по номеру строки на экране. Исходный порядок сохраняется. Трёхбуквенные метки языка передаются tsMuxer, неизвестные обозначаются `und`. Название исходной дорожки показывается в редакторе и на странице «Аудио» дискового меню. Его можно изменить двойным щелчком в предпросмотре. В штатном списке дорожек самого проигрывателя это название может отсутствовать.

В главном меню ISO выберите «Аудио», затем дорожку стрелками и нажмите OK. Выбор применяется при запуске фильма и при переходе к главам. По умолчанию используется первая включённая дорожка. До пяти дорожек показаны на странице; остальные доступны через кнопки перехода. Если звук не включён, раздел не создаётся.

Во время просмотра нажмите Pop-up Menu: фильм ставится на паузу и открывается страница текущей дорожки; при наличии субтитров откроется главное меню, где нужно выбрать «Аудио». Выберите другую и нажмите OK — просмотр продолжится. Back, повторное Pop-up Menu или кнопка «Назад» возвращают к фильму без смены звука. Back непосредственно во время фильма сохраняет прежнее действие: возврат в главное меню с остановкой. Выбор действует в текущем сеансе воспроизведения.

Авторинг сверяет список с primary audio STN готового MPLS. BD-J использует `PrimaryAudioControl.selectStreamNumber()` с номерами от 1, а не исходными индексами FFprobe. Неподдерживаемый выбор вызывает ошибку; приложение не подменяет озвучку молча. Для работы нужен проигрыватель с BD-J.

Чтобы добавить страницу в ранее созданный ISO DiscForge, загрузите меню из ISO и сохраните текущее меню в новый образ. Дорожки берутся из существующего плейлиста: отсутствующие в нём дорожки этим способом добавить нельзя. В старых образах без сохранённых названий показываются язык и номер. Видео и звук не перекодируются. Выбор субтитров описан в [отдельном разделе](SUBTITLES.md). DTS, TrueHD, LPCM и AAC сейчас преобразуются, их копирование без потерь не заявляется.

Проект хранит выбранные индексы отдельно для каждого файла. Если после повторного анализа выбранного потока уже нет, фильм не принимается в очередь с неправильной дорожкой: появится ошибка, его нужно добавить заново. Ограничения размера диска и битрейта пересчитываются при изменении выбора.
