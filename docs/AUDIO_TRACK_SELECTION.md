# Выбор исходной аудиодорожки для Full HD Blu-ray

**Реализовано в CLI:** можно выбрать одну аудиодорожку входного файла
(нумерация начинается с 0). Видеопотоки и субтитры, вставленные между
аудиопотоками, не влияют на индекс: используется `-map 0:a:N`.

```shell
python cli.py probe film.mkv
python cli.py build film.mkv --profile BD25 --folder --audio-index 1
```

Команда `probe` показывает список `audio_details`: индекс, codec, channels
и language. Выбранная дорожка перекодируется в **одну** AC-3 48 kHz
дорожку (до 5.1), затем tsMuxer включает её в BDMV/ISO.
При выборе дорожки с 1–2 каналами формируется стерео;
при 3 и более — 5.1. Настоящая многодорожечная Blu-ray-компоновка
пока не реализована. GUI по-прежнему выбирает первую дорожку по умолчанию.

Индекс вне диапазона, отрицательный индекс и попытка выбрать звук
в файле без аудио отвергаются до создания результата. Некорректные
метаданные каналов также отвергаются. Если `--audio-index` не указан,
сохраняется старое поведение: берётся первая дорожка или видео без звука.

**Проверки:** `python -m unittest discover -s tests -v`;
`tests/test_audio_tracks.py` проверяет разбор ffprobe,
`tests/test_audio_cli_integration.py` — подключение CLI к FFmpeg.
Автоматические проверки не подтверждают реальную совместимость с приводом
ASUS BW-16D1HT или бытовыми проигрывателями.
