# BD-J авторинг в DiscForge RU 1.1

Версия 0.2 впервые включает настоящий исполняемый Xlet, а не только модель
навигации. `bdj_menu.py` остаётся исследовательской моделью расширенных экранов;
текущий дисковый формат и редактор используют `disc_menu.py`.

## Конвейер

1. FFmpeg копирует или преобразует видео и выбранный звук; tsMuxer создаёт один плейлист 00000 с главами.
2. Авторинг проверяет, что каждому пункту главы соответствует EntryMark.
3. Qt рисует PNG-страницы 1920×1080 с выбранными системными или комплектными шрифтами Noto. Один
   рендерер используется для предпросмотра и ресурсов на диске.
4. `BDMV/JAR/00000.jar` содержит собственный Xlet, страницы и конфигурацию.
   `BDMV/BDJO/00000.bdjo` описывает приложение. Index направляет First Playback,
   Top Menu и единственный title в это приложение. Метаданные дублируются в BACKUP.
5. Структура BDMV проходит проверки. Для ISO Windows IMAPI2FS формирует
   UDF 2.50 с резервными метаданными; затем отдельно проверяется UDF.
6. Только успешный результат перемещается из временной папки в выходную.

Экран выбора глав теперь отображает до пяти глав на странице: кнопки
«Предыдущие главы» и «Следующие главы» позволяют листать в обе стороны,
а «Главное меню» доступно на каждой странице. На первой/последней странице
несуществующие переходы не показываются. Пользователь может
добавлять кнопки (до 16 видимых на странице) и менять их геометрию. Xlet
читает координаты и действия из menu.properties, выделение загружает из сглаженных PNG; эти же данные использует предпросмотр. В исходники включён
пересобранный Xlet. Пользователю не нужна Java для сборки меню.

Раздел «Аудио» содержит только включённые primary audio дорожки. `disc_audio.py` читает ограниченный MPLS/STN, проверяет границы и порядок потоков. Страницы аудио добавляются после страниц глав. Действие `audio:N` использует номер потока от 1; язык и название озвучки запекаются в PNG, русскому тексту не нужны шрифты плеера.

Xlet подготавливает Player через prefetch, применяет `PrimaryAudioControl` и запускает выбранную главу. Pop-up Menu во время фильма приостанавливает скорость воспроизведения и показывает аудио; выбор/Back возобновляют текущий Player. Новый Player при смене дорожки не создаётся. Back непосредственно во время фильма и конец фильма возвращают главное меню. Ошибка переключения сохраняет доступ к приостановленному Player.



### Проверка привязки глав перед выпуском меню

Для каждого пункта «Глава» до создания JAR выполняется ограниченное чтение
MPLS (не больше 16 МиБ), сверяется число EntryMark с числом глав проекта,
проверяются границы секций PlayList/PlayListMark и ссылки отметок на существующие
PlayItem. EntryMark дополнительно проверяются в 45-кГц шкале каждого PlayItem
с учётом предшествующих PlayItem: отметки обязаны строго возрастать и
соответствовать заданным главам с допуском до 2 секунд на привязку к GOP.
Неверные, дублирующиеся, неупорядоченные или бесконечные временные метки
глав не допускаются. Ошибка прерывает установку меню до записи ресурсов
BDJO/JAR; это не заменяет общую структурную проверку BDMV.

Регрессии (включая поддельные длины секций):
`python -m unittest discover -s tests -p 'test_disc_menu_preflight.py' -v`.
Проверки синтетические и сами по себе не подтверждают работу на бытовом плеере.

Проверки временных отметок: `python -m unittest discover -s tests -p 'test_chapter_timeline.py' -v`.

## Сборка Xlet

Готовый `assets/bdj/menu.jar` включён в исходники. Пользователю не нужны Java,
ECJ или BD-J SDK для создания диска. Для пересборки требуется Java 8,
Eclipse ECJ 3.26.0 и BD-J API classes.zip:

```text
python tools/build_bdj.py --java /path/to/java --ecj /path/to/ecj.jar --api /path/to/classes.zip
```

Проверенная API-основа: HD Cookbook `lib/stubs/enhanced/classes.zip` из
https://github.com/cheeseb1234/auto-bluray-tui . Компилятор создаёт Java 1.3
bytecode (major 47). JAR включает только наш класс, MIT license и манифест;
API-заглушки и сторонние runtime-классы в него не попадают. В манифесте есть
SHA-256 исходника, чтобы тесты обнаруживали забытый rebuild.

## Воспроизводимая проверка реальными инструментами

```text
python tools/smoke_authoring.py --ffmpeg /path/to/ffmpeg --ffprobe /path/to/ffprobe --tsmuxer /path/to/tsMuxeR --output /new/test/folder
```

Создаётся 12-секундный тестовый фильм с тремя главами (0, 4, 8 секунд), затем
реальные H.264/AC-3, BDMV с меню и ISO. `--folder` останавливается на BDMV.
Скрипт не использует привод и не перезаписывает существующий тестовый исходник.

Проверено локально на Windows: FFmpeg 9.0.2, tsMuxer 2.7.0, UDF 2.50 через
IMAPI2FS; 12-секундный ISO 39 190 528 байт прошёл структурные проверки.
VLC 3.0.23 + libbluray 1.4.0 + Temurin 8 распознали BD-J и выполнили
переход с главного экрана в главы и запуск второй главы (тестовая картинка
с таймкодом около 00:00:04). Автоматический захват через vmem выявил ошибку
самого пути вывода VLC «blending BGRA to I420 failed», поэтому такой захват
не подтверждает визуальное воспроизведение меню. Внешний захват окна также
не завершился; аппаратные и визуальные playback-проверки остаются открытыми.

Windows-сборка зафиксирована на PySide6 Essentials 6.8.3 и проверена после
упаковки PyInstaller: `DiscForge_RU.exe --self-test report.json` запускает
настоящее окно offscreen, рендерит меню и проверяет ресурсы JAR/IMAPI.
Такая же проверка обязательна в Windows CI; пользовательские настройки
при ней не сохраняются. Qt 6.12 в локальной упакованной сборке не прошёл
загрузку DLL и не входит в проверенную конфигурацию.

## Дополнительные испытания и развитие после 1.1

- Минимум два бытовых плеера разных производителей: First Play, стрелки,
  OK, последняя страница глав, Back, Top Menu, конец фильма и повторный старт.
- Проверить BD25/BD50 и BD-R/BD-RE, финализацию и полную проверку записи.
- Длительные фильмы, кириллица/длинные названия, 7+ глав, повторная загрузка диска.
- Проверить unsigned sandbox Xlet на аппаратных реализациях BD-J;
  подпись и привилегированные операции не используются.
- Расширить форматы дорожек, добавить субтитры, многотитульные диски, продолжение,
  шаблоны с обложками, сохранение подходящей исходной частоты кадров.

Успешный preflight и воспроизведение через libbluray не являются сертификацией
BD-ROM и не гарантируют поддержку всеми бытовыми устройствами.

## Актуализация 1.1

Рендерер больше не рисует декоративные круги. Темы midnight/graphite/cinema, скрытые тексты, стили и геометрия сохраняются в `discforge-design.json` внутри JAR. Предпросмотр и ISO используют один рендерер. Фокус кнопки — непрозрачный фрагмент страницы с качественно сглаженной обводкой; Java не рисует повторные дуги. Выбранные звуковые потоки записываются в tsMuxer meta по отдельности с метками языка.
