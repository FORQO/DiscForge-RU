# BD-J: проверка доступности страниц меню

Перед установкой Xlet в BDMV валидатор проверяет **весь достижимый граф
кнопок**, а не останавливается при первом `play:0` на главном экране.

Если пользователь удалил все кнопки на странице выбора глав или аудио, но
ссылка на страницу осталась, публикация меню прерывается с сообщением
«Доступная страница меню осталась без кнопок». Это предотвращает экспорт
страниц, на которых стрелки/OK пульта ничего не делают. Верните кнопку
или уберите вход в этот раздел. Намеренно скрытая и недостижимая страница
не считается ловушкой для пульта; существующее требование доступной
кнопки воспроизведения сохраняется.

Проверка полностью статическая; корректность реакций на кнопки пульта
и совместимость с бытовым Blu-ray-плеером **не подтверждены**.

Регрессионные тесты:
`python -m unittest discover -s tests -p 'test_menu_navigation_dead_ends.py' -v`.
