# Автоподбор битрейта

Включено в DiskForge 1.4.0.

Добавьте фильмы и дождитесь анализа. В «Подготовке» новый проект использует **«Авто — отдельно для каждого фильма»**. Таблица «План диска» показывает исходный видеобитрейт, способ обработки, целевой битрейт и оценку размера потоков каждого фильма. Выбор строки переключает текущий фильм.

Совместимое видео рекомендуется копировать: его качество и битрейт сохраняются. Звук обрабатывается независимо, согласно выбору дорожек. Для несовместимого видео программа предлагает экономный ориентир H.264, исходя из разрешения, исходного кодека и видеобитрейта. Перекодирование не бывает гарантированно без потерь; автоматический подбор не измеряет визуальное качество и не восстанавливает детали небольшого рипа.

Например, для H.264 1024×426 с низким исходным битрейтом ориентир — 5 Мбит/с вместо прежних общих 12. Для фильма 2:31:19 это около 5,67 ГБ видео вместо 13,62 ГБ; выбранный звук, субтитры и служебные данные прибавляются отдельно. Это пример расчёта, не обещание одинакового качества любых фильмов.

Для ручной поправки выберите фильм и включите **«Задать битрейт для выбранного фильма»**. Диапазон этой версии — 5–28 Мбит/с. Настройки сохраняются в проекте. Кнопка **«Применить автоподбор ко всем фильмам»** сбрасывает индивидуальные значения, включает автоматический выбор копирования/кодирования и сбалансированный режим кодера. Старые проекты открываются с прежним ручным режимом; автоподбор можно включить явно.

Добавление новых серий не снижает битрейт остальных. При нехватке места программа предупреждает и блокирует сборку. Можно убрать лишние дорожки, изменить состав диска, выбрать BD50 или осознанно уменьшить ручной битрейт. В таблице указана сумма потоков; меню, контейнер и общий запас включены в шкалу слева. Фактический размер проверяется после сборки.

## Как получается рекомендация

Берётся средний битрейт именно видеопотока: по всем пакетам при выполненной проверке копирования, затем по метаданным потока. Если этих данных нет, ffprobe читает короткие пробы в трёх местах фильма. Короткие пробы дают приблизительный результат и могут пропустить сложные сцены. Размер MKV вместе с аудиодорожками не используется вместо видеобитрейта. Если измерение невозможно, интерфейс сообщает о недостатке данных и использует более осторожный ориентир.

Эвристика приложения: нижний ориентир 5 / 6 / 8 / 10 Мбит/с для размеров до 0,7 / 1,1 / 2,3 / свыше 2,3 миллиона пикселей. Исходный битрейт умножается на 1,25 для AVC/VP8, на 2 для HEVC/AV1/VP9, на 1 для остальных кодеков. Выбирается большее значение, округлённое вверх до 0,5 Мбит/с, с пределом 28 Мбит/с. При неизвестном битрейте ориентир не ниже 8 Мбит/с для небольшого кадра и 12 для остальных. Это начальные настройки DiskForge, **не требования стандарта Blu-ray и не доказанный порог прозрачности**. HDR по-прежнему требует отдельной реализации тонмаппинга.

Сбалансированный режим по умолчанию: NVENC p5 или x264 medium. Более быстрый режим остаётся доступен. Механика чтения пакетов описана в [документации ffprobe](https://ffmpeg.org/ffprobe.html); параметры NVENC — в [руководстве NVIDIA](https://docs.nvidia.com/video-technologies/video-codec-sdk/13.0/ffmpeg-with-nvidia-gpu/index.html). Числа эвристики выше выбраны приложением, а не взяты из этих документов.

## Проверки

Автотесты проверяют индивидуальные рекомендации, копирование без изменения потока, сохранение проектов, подсчёт места и отказ при переполнении без скрытого уменьшения битрейта. Реальный тест создаёт два коротких медиафайла, кодирует их с разными значениями 5 и 6,5 Мбит/с и собирает общий ISO с проверкой структуры, связей меню и SHA-256 содержимого. Это техническая проверка конвейера; субъективное сравнение качества полнометражных фильмов и испытание на бытовом плеере в неё не входят.
