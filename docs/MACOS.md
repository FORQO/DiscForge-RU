# DiskForge Studio 1.5.1 для macOS — кандидат

[Стабильный выпуск 1.5.0](https://github.com/FORQO/DiscForge-RU/releases/tag/v1.5.0-studio) для Apple Silicon (M1 и новее). Python, Qt, FFmpeg, ffprobe,
tsMuxer, Java 8 и модуль UDF 2.50 входят в `.app`. Установка Python или Homebrew для
запуска готового приложения не требуется. Сборка для Intel здесь не проверена.

Описание кандидата и незавершённые проверки: [Studio 1.5.1](RELEASE_STUDIO_1.5.1.md).

## Запуск

Распакуйте ZIP и перенесите `DiskForge.app` в «Программы» либо запустите из папки
распаковки. Сборка имеет локальную ad-hoc подпись, без Developer ID и нотарификации
Apple. Если macOS блокирует скачанную сборку, используйте «Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть» для этого приложения.

Добавьте фильмы, настройте меню, главы и дорожки и нажмите «Создать ISO…». В отдельном окне выберите BD25/BD50, формат ISO/BDMV и папку результата.
Доступны папка BDMV и ISO UDF 2.50, включая меню и коллекции. Завершённые этапы
сохраняются в кэше; созданный образ проверяется и подключается только для чтения
для сверки содержимого. Меню своего однотитульного ISO можно обновить в новый образ.

На Mac перекодирование выполняет CPU x264. Совместимое видео копируется без
перекодирования. NVIDIA CUDA/NVENC недоступны; VideoToolbox в эту адаптацию не входит.
⌘N — новый проект, ⌘O — открыть, ⌘S — сохранить. Настройки находятся в
`~/Library/Application Support/DiscForgeRU/settings.json`.

## Просмотр и запись

VLC устанавливается отдельно в `/Applications/VLC.app` или `~/Applications/VLC.app`.
Для интерактивных меню BD-J используется комплектная Java 8 arm64 и VLC arm64.
Если комплектный runtime отсутствует, приложение ищет Java через `JAVA_HOME`, `/usr/libexec/java_home` и стандартные каталоги JDK.
Отсутствие Java не мешает созданию ISO. Проверка запуска меню на физическом
Blu-ray-плеере остаётся отдельным этапом; автоматические проверки этого не доказывают.

Запись из GUI пока не реализована. Из исходников можно использовать терминальный модуль:

```bash
python3 macos_burn.py drives
python3 macos_burn.py burn "/путь/к/фильму.iso" --dry-run
python3 macos_burn.py burn "/путь/к/фильму.iso" --speed 2 --yes
```

Он использует `hdiutil burn` с проверкой записи. Тесты адаптации не записывают носители.

## Сборка из исходников

Нужны Python 3.11+, Xcode Command Line Tools и FFmpeg (например, `brew install ffmpeg`).

```bash
bash start_macos.command --prepare-only
bash build_app_macos.sh
```

При необходимости задайте `DISKFORGE_PYTHON`, `DISKFORGE_FFMPEG`, `DISKFORGE_FFPROBE`.
Результат: `dist/DiskForge.app` и ZIP; проверка комплектного приложения:
`build/macos-self-test.json`. Сборщик не изменяет системную установку Python.

`tools/build_macos_tools.py` загружает исходники tsMuxer по фиксированному commit
и проверяет SHA-256; CLI 2.7.0 arm64 также закреплён контрольной суммой.
`discforge-udf` использует Apache-2.0 IsoWriter tsMuxer с локальными исправлениями
для каталогов более одного сектора и идентификаторов более 255 файлов.
Внутренние имена Blu-ray должны быть ASCII; пути к исходным видео, папке результата
и названия меню могут содержать кириллицу и пробелы. Исходный модуль и исправления
находятся в `tools/macos_udf.cpp` и `tools/patch_macos_udf.py`.

## Интерфейс Studio

Библиотека фильмов находится слева, редактор — в центре, свойства — справа.
Свойства меню разделены на «Оформление», «Объект» и «Расстановка».
Щелчок по объекту открывает его свойства; двойной щелчок по тексту позволяет
редактировать его прямо на холсте.

«Предпросмотр» скрывает свойства и показывает пульт под изображением.
Для возврата к настройкам нажмите «Редактировать». Журнал открывается кнопкой
внизу окна и раскрывается при ошибке. Светлая и тёмная темы доступны в меню «Темы».
Минимальное окно — 1040 × 680; на небольшом экране свойства прокручиваются отдельно.
