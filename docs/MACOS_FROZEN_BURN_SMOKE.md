# Автономный macOS burner: проверка перед публикацией

После сборки PyInstaller проверяется **сам исполняемый файл**
`dist/DiscForge-RU-burn`, а не только Python-модули. Это позволяет
заметить ошибки упаковки импортов и нарушения поведения CLI.

Запуск на macOS из корня репозитория:

```bash
python3 tests/smoke_macos_burn_cli.py dist/DiscForge-RU-burn
```

Пять сценариев: проверка синтетического UDF 2.50 для BD25 и BD50,
положительный `burn --dry-run`, отказ при повреждённом UDF в режимах
`check` и `burn --dry-run`. Те же проверки запускаются в macOS
GitHub Actions до загрузки сборочного артефакта.

**Ограничения:** ISO-тестовый файл содержит лишь искусственные метаданные
UDF; это не монтируемый Blu-ray и не полноценный BDMV. Эти сценарии не
обращаются к оптическому приводу, не проверяют BD-J/HDMV и не заменяют
физические испытания ASUS BW-16D1HT, запись BD-RE и воспроизведение
на бытовом Blu-ray-плеере.
