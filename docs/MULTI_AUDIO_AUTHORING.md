# Несколько выходных дорожек AC-3 (экспериментально)

DiscForge RU теперь поддерживает выбор **от одной до восьми** исходных
аудиодорожек и кодирует каждую в отдельную AC-3 48 kHz (до 5.1).
Порядок аргументов определяет порядок дорожек на диске.

```sh
python cli.py probe film.mkv
python cli.py build film.mkv --folder --profile BD25 \
  --audio-track 1 --audio-track 0
```

Для одной дорожки прежний аргумент `--audio-index N` сохранён.
Нельзя одновременно использовать `--audio-index` и `--audio-track`.
GUI пока использует прежний выбор **одной** дорожки: новые параметры
доступны в CLI. Видео без аудио остаётся допустимым без аргументов
выбора звука.

Список дорожек извлекается из `ffprobe` (индексы только аудиопотоков,
нумерация с нуля), а не из глобальных stream IDs. Повторные, несуществующие,
отрицательные и булевы индексы блокируются до запуска кодирования.
Отсутствующие метаданные при многодорожечном выборе — ошибка.
Языковые теги приводятся к безопасному трёхбуквенному коду ISO 639-2;
неизвестные значения записываются как `und`.

Бюджет BD25/BD50 учитывает 640 кбит/с **на каждую** аудиодорожку,
а итоговый размер проверяется существующей проверкой публикации.
Многодорожечная композиция в tsMuxer выполняется через отдельные
строки `A_AC3` в `.meta`.

## Проверка перед выпуском

```sh
python -m unittest tests.test_multi_audio_authoring -v
python -m unittest discover -s tests -v
```

Это программная реализация со структурными тестами, **не подтверждение**
корректного переключения аудио пультом, BD-J Audio-меню или воспроизведения
на бытовых плеерах. Для проверки нужны созданный tsMuxer BDMV,
инспекция M2TS/CLPI/MPLS, запись BD-RE и физический тест на ASUS
BW-16D1HT с реальным плеером. ISO UDF 2.50 и запись на привод
проверяются независимо на Windows и macOS. DRM не обходится.
