# DiscForge RU 1.0

Первый официальный выпуск для Windows 10/11 x64: создание Blu-ray ISO с пользовательским интерактивным меню, главами и выбранными аудиодорожками.

## Новое и доработанное

- Лаконичное оформление без декоративных кругов, спокойная тёмная тема и серая «Графит». Прежний «Кинотеатр» сохранён.
- Один щелчок выбирает текст/кнопку для перемещения; двойной открывает редактирование. Del удаляет любой выделенный текст, включая название и подсказки. Во время ввода Del удаляет символы.
- Перетаскивание, изменение размеров, мягкие направляющие, шрифты, цвета, формы и обводки. Сглаженное выделение одинаково в предпросмотре и ISO.
- Раздел «Аудио» показывает все дорожки после анализа. Галочки задают состав образа отдельно для каждого фильма; выбор сохраняется в проекте.
- Автоматическая рекомендация учитывает выбранный звук, размер и суммарный битрейт. Подходящие видео/AC-3 копируются без потерь; при необходимости преобразуются только неподходящие звуковые дорожки.
- Сохраняются функции предыдущих сборок: ручные главы, свой фон, RU/EN, дополнительные кнопки, полный экран, прошедшее время/ETA, выбор папки, проверка ISO в VLC с отдельной Java, замена меню готового ISO без обработки фильма.
- Переписаны руководство, Roadmap, описание продукта и инструкции выпуска; добавлены раздел аудио и указатель технических документов.

## Скачать и запустить

Распакуйте **весь** `DiscForge-RU-1.0.0-Windows-x64.zip`, запустите `DiscForge_RU/DiscForge_RU.exe`. В комплекте FFmpeg/ffprobe 9.0.2, tsMuxer 2.7.0, Java 8 x64 и лицензии. VLC x64 устанавливается отдельно. Приложение не имеет цифровой подписи. Архивы исходников доступны по тегу; контрольная сумма portable ZIP находится в `SHA256SUMS.txt`.

Старые проекты открываются. Настройки оформления могут получить обновлённый рендеринг; готовые старые ISO сами по себе не изменяются. Для старого ISO доступно исправление обводки, для ISO 0.9+ — загрузка редактируемого дизайна.

## Проверено

- 362 автоматических теста: 355 прошли, 7 пропущены по платформе/условиям среды на локальной Windows-проверке.
- Реальные короткие сборки: выбранная вторая AC-3, смешанный AC-3/AAC, отсутствие звука и ISO с двумя дорожками.
- Побайтовое совпадение скопированного AC-3; совпадение всех декодированных видеокадров после копирования.
- Подключение ISO Windows, две звуковые дорожки, языки `rus`/`eng` в плейлисте, чтение сохранённого дизайна.
- Замена меню: неизменные хеши M2TS/MPLS/CLPI, неизменный исходный ISO, сохранение удалённых текстов.
- Упакованный EXE: запуск окна, рендеринг, ресурсы Xlet/IMAPI, комплектная Java, кнопки VLC и полного экрана.
- Кнопка VLC запускает отдельный процесс с Java; загрузились Xlet и страница меню с выделением. Проверка автоматическая, с dummy-видеовыводом и отключённым звуком, без оценки визуального воспроизведения и прослушивания.

## Ограничения

Один фильм на диск, AC-3 как выходной звук, без субтитров и HDR/UHD. Аудиодорожки переключаются средствами проигрывателя, отдельного BD-J экрана аудио пока нет. macOS — экспериментальное направление. Физическая запись и бытовые плееры разных производителей ещё не проверены; структурные проверки и VLC не являются сертификацией Blu-ray.

Дальнейшая работа: надёжность на реальных плеерах, расширение аудиоформатов и субтитры, многотитульные диски. См. [Roadmap](https://github.com/maxliv234-star/DiscForge-RU/blob/main/docs/ROADMAP.md).
