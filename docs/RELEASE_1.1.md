# DiscForge RU 1.1.1

В 1.1.1 исправлена проверка готовности PNG в BD-J: полностью декодированная картинка принимается по флагу ALLBITS, даже если проигрыватель затем сообщает ABORT. Чтение ресурса выполняется в контексте Xlet, загрузка и смена выделения — рабочим потоком.

Выбор языка и озвучки теперь доступен в меню самого Blu-ray диска.

## Как пользоваться

1. В разделе «Аудио» программы отметьте дорожки, которые должны попасть в образ.
2. В предпросмотре откройте кнопку «Аудио»: там показаны язык и название каждой выбранной озвучки. Подписи и оформление можно редактировать.
3. На проигрывателе откройте «Аудио», выберите дорожку стрелками и нажмите OK. Этот выбор применяется при запуске фильма и глав.
4. Во время фильма Pop-up Menu открывает выбор звука с паузой. OK переключает дорожку и продолжает фильм. Back, повторное Pop-up Menu или «Назад» продолжают без смены звука.

До пяти дорожек на странице, до 32 в образе. Без включённых дорожек раздел не появляется. Для прежнего ISO DiscForge можно загрузить меню и сохранить его в новый образ: аудиоменю добавляется по существующему плейлисту, без перекодирования. Добавление отсутствующего звука требует новой сборки.

## Проверки

- 370 автоматических тестов: Windows — 363 пройдены, 7 пропущены по платформенным условиям.
- Реальный 60-секундный H.264/AC-3 файл: из трёх исходных дорожек включены первая и третья, в меню они соответствуют потокам Blu-ray 1 и 2. Исключённая дорожка отсутствует; включённый AC-3 совпадает побайтно.
- Реальный ISO UDF 2.50: повторное сохранение меню сохранило M2TS, MPLS и CLPI побайтно.
- VLC 3.0.23 / libbluray 1.4.0 / комплектная Java 8: навигация BD-J через команды пульта, выбор до запуска и переключение во время фильма. Активный поток VLC изменился с PID 4353 на 4352; позиция при возобновлении сохранилась с расхождением менее 0,1 секунды. Проверен возврат из Pop-up Menu без смены дорожки. Вывод аудио/видео в этой автоматизированной проверке был виртуальным.

Бытовой Blu-ray проигрыватель и физический диск в этой проверке не использовались. Требуется поддержка BD-J; совместимость со всеми моделями не заявляется. Выбор сохраняется на время текущего сеанса, не между запусками диска. Back непосредственно во время фильма по-прежнему останавливает его и возвращает главное меню.

Windows portable-комплект включает FFmpeg, ffprobe, tsMuxer и Java для запуска через кнопку VLC. Сам VLC устанавливается отдельно. Выпуск 1.0 остаётся доступен под прежним тегом.
