# DiskForge 1.2.0

Новый фирменный логотип и графитовый интерфейс с оранжевыми акцентами. Прежняя синяя тема сохранена в меню **Темы**. Логотип используется в приложении, значке Windows, меню диска и документации.

Добавлен раздел **Субтитры**: выбор встроенных текстовых и PGS-потоков, внешние SRT/SUP, язык и название дорожки, сохранение выбора в проекте. На диске появился экран выбора субтитров и пункт **Выключить**. Переключение работает до запуска фильма и через Pop-up Menu во время просмотра, с продолжением с текущей позиции.

SRT преобразуется в отдельный PGS, без наложения текста на видео. Исправлена подготовка окончания SRT для tsMuxer 2.7, чтобы последняя реплика не терялась. В режиме копирования видео и совместимые аудиодорожки сохраняются. Обновление меню готового ISO сохраняет существующие субтитры.

## Проверки

- 381 автоматический тест (374 пройдены, 7 пропущены по платформе): выбор и исключение потоков, кодировки и тайминги SRT, MPLS, меню до 32 дорожек, проекты, темы, авторинг и прежние функции.
- Реальный 60-секундный ISO: встроенные русские и внешние английские субтитры, исключённая французская дорожка, два потока PGS. Проверено наличие пакетов с субтитрами, а не только записей в плейлисте.
- Сохранение выбранного AC-3 побайтно и совпадение хешей декодированных видеокадров при копировании.
- VLC 3.0.23 / libbluray 1.4.0 / комплектная Java 8: команды пульта, выбор субтитров до запуска, переключение 4608 → 4609 → выключено, продолжение с сохранением позиции. Дополнительно проверен вывод текста поверх видео.
- Замена меню тестового ISO сохранила M2TS/MPLS/CLPI побайтно.
- Portable EXE проходит самостоятельную проверку окна, ресурсов и комплектной Java.

Бытовой проигрыватель и физический диск в этих испытаниях не использовались. Поддержка BD-J зависит от устройства. VobSub и полное оформление ASS/SSA пока не поддерживаются. Добавление новых файлов субтитров в ISO требует новой сборки, но совместимое видео можно копировать без перекодирования.

Распакуйте весь ZIP и запустите `DiscForge_RU.exe`. FFmpeg, ffprobe, tsMuxer и Java включены; VLC x64 устанавливается отдельно. Имена EXE и репозитория сохранены для совместимости. [Инструкция по субтитрам](SUBTITLES.md).
