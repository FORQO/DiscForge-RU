# DiskForge 1.3.1

Названия сцен из MKV автоматически появляются в меню диска вместе с готовыми таймингами. Вместо «Глава 1» программа использует исходное название, если оно есть.

## Как редактировать

Откройте страницу глав в предпросмотре меню. Дважды нажмите на название сцены и введите свой текст либо выберите кнопку и измените подпись в правой панели. «Сбросить подпись» возвращает название из файла. Правки сохраняются для русского и английского меню отдельно; исходное название не переводится автоматически.

Названия сохраняются в проекте отдельно для каждого фильма и не заменяются повторным анализом. При правке времени или добавлении/удалении соседних глав подпись остаётся привязанной к своей сцене. Встроенный в ISO проект меню тоже содержит названия: их можно исправить через обновление меню без перекодирования.

## Проверено

- Разбор заголовков ffprobe, кириллица, регистр тегов, отсутствующие/некорректные названия, сортировка и дубликаты времён.
- Двойной щелчок в предпросмотре, переименование и сброс; повторный анализ, сохранение и открытие проекта, миграция старых проектов, отдельные названия для фильмов в очереди.
- Реальная сборка UDF 2.50 ISO из тестового MKV с шестью именованными главами в режиме копирования потоков. Названия сохранены на обеих страницах глав и во встроенном проекте.
- Переименование главы при обновлении готового ISO: M2TS, MPLS и CLPI до и после имеют одинаковые SHA-256.
- Portable-пакет проходит встроенный `--self-test`; содержит инструменты и отдельную Java 8 x64.

## Ограничения

Используется линейный список глав и тег `title`, которые возвращает ffprobe. Вложенные/упорядоченные редакции Matroska отдельно не обрабатываются. Названия нормализуются до одной строки длиной до 120 символов. Если названия нет, остаётся «Глава N». Более 999 глав автоматически не импортируются.

Старый ISO не содержит названий, которых не было при его сборке: их можно вписать вручную в редакторе меню или собрать новый ISO из MKV. Аппаратное воспроизведение этого выпуска на бытовом Blu-ray-плеере не проверялось; остальные возможности и ограничения описаны в [руководстве](USER_GUIDE.md).
