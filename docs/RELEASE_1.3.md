# DiskForge 1.3.0

Готовые главы из MKV теперь автоматически становятся главами Blu-ray и кнопками меню. Настройки меню перенесены вправо, чтобы освободить место предпросмотру. Фирменный логотип получил прозрачный фон, а графитовая тема стала светлее.

## Изменения

- При анализе ffprobe извлекает готовые отметки глав. Их порядок и точность нормализуются до миллисекунд; дубликаты объединяются, начало фильма добавляется при необходимости.
- Сохранённые в проекте и вручную изменённые тайминги имеют приоритет перед автоимпортом. «Вернуть главы из файла» восстанавливает исходные отметки.
- Тайминги используются и в плейлисте MPLS, и в меню BD-J. Импорт не требует перекодирования фильма. Названия глав редактируются отдельно в меню.
- Правая панель с независимой прокруткой и изменяемой шириной. Выбор элемента в предпросмотре открывает его оформление. Перемещение, двойной щелчок, Del и F11 сохранены.
- Прозрачный логотип в окне и на диске; крупный диск с искрой в иконке приложения. Графит стал светлее, синяя тема остаётся доступной.

## Проверено

- Разбор глав: дробные тайминги, time_base, дубликаты, сортировка, отсутствующие и ошибочные отметки, ограничение 999 глав.
- Автоматический импорт в редактор; сохранение ручных правок при повторном анализе и после открытия проекта; восстановление исходных глав; несколько фильмов в очереди.
- Реальный MKV с шестью встроенными главами: `0`, `10.250`, `20.750`, `30.500`, `40.900`, `50.000` секунд. Собран UDF 2.50 ISO без перекодирования видео и AC-3. После подключения ISO все отметки MPLS совпали с исходными, меню содержит две страницы глав.
- Рендер графитовой и синей тем, прозрачность PNG, иконка ICO, существующие проверки редактирования мышью и полного экрана.
- Portable EXE проверяется через `--self-test`; пакет включает инструменты и отдельную Java 8 x64 для VLC.

## Ограничения

Импортируются тайминги, а не названия или вложенные/упорядоченные редакции Matroska. Используется линейный список, который возвращает ffprobe. Более 999 глав не импортируются автоматически; причина отображается в журнале. Файл без глав можно разбить вручную или по интервалу.

В существующем ISO главы остаются прежними: для новых таймингов нужна новая сборка из фильма, с копированием совместимых потоков. Замена меню готового ISO применяет новое оформление без перекодирования.

Переход при воспроизведении зависит от ключевых кадров и плеера. Структурная проверка ISO не заменяет воспроизведение и физическую запись. На бытовом Blu-ray-проигрывателе этот выпуск не проверялся.
