# Roadmap

Текущий выпуск: **DiskForge 1.4.0**, Windows x64. Даты следующих выпусков зависят от проверок; ниже приоритеты, а не обещание сроков.

## Выпущено в 1.4.0

- [x] Общий диск с несколькими фильмами, автоматическим каталогом и страницами, отдельными главами, аудио и субтитрами.
- [x] Названия и порядок фильмов, живой предпросмотр каталога; явная принадлежность глав своему фильму.
- [x] Шкала BD25/BD50, учёт выбранных дорожек и запаса, предупреждение и блокировка переполнения.
- [x] Автоматический битрейт для каждого фильма, измерение исходного видеобитрейта, ручные поправки и таблица размеров.
- [x] «Кино · Янтарь» / «Кино · Сапфир», удаляемый логотип, компактная шапка и значок полного экрана.
- [x] Сохраняемые этапы, возобновление, контроль исходников/инструментов/результатов по SHA-256.
- [x] NVDEC/CUDA/NVENC с проверкой исходника; температура, GPU/NVENC и предупреждение о нагреве.
- [x] Более строгая проверка AVC: профиль, уровень, GOP/IDR, параметры и временные метки.
- [x] Независимые политики аудио, сохранение поддерживаемых AC-3/DTS core/LPCM и TrueHD/Atmos.
- [x] Проверка связей меню/плейлистов/глав/дорожек, содержимого ISO, отчёты и подробный прогресс проверки.
- [x] Пункт Проводника «Открыть Blu-ray в VLC» с Java из комплекта.
- [x] Реальные короткие медиа-регрессии, исправления длинного пути, записи M2TS и готовности смонтированного ISO.

Прямое изменение меню готовой коллекции пока заменяется пересборкой проекта с проверенным кэшем видео/аудио.

- [x] Автоматическая рекомендация и копирование совместимых H.264/AC-3 без перекодирования.
- [x] Раздел аудио с выбором нескольких дорожек и сохранением выбора.
- [x] Пользовательские тайминги глав и автоматическое разбиение.
- [x] Реальное BD-J меню, русский/английский текст, свой фон.
- [x] Тёмное и серое оформление, добавление кнопок, стили текста и обводки.
- [x] Перемещение, размер, мягкое выравнивание, выделение одним и редактирование двойным щелчком, удаление Del.
- [x] Полноэкранный предпросмотр и запуск ISO в VLC с отдельной Java.
- [x] Исправление/замена меню готового собственного ISO без обработки фильма.
- [x] Выбор выходной папки, прогресс, прошедшее время, ETA, отмена.
- [x] Автоматические проверки, воспроизводимая Windows-сборка, руководство и релизные материалы.

## Далее — надёжность и обратная связь

Автоматические проверки и VLC не подменяют [физические плееры](PLAYER_TEST_MATRIX.md). Следующие приоритеты:

- [ ] Матрица бытовых плееров разных производителей: First Play, главы, Back, Top Menu, конец фильма.
- [ ] Физические испытания BD-R/BD-RE, BD25/BD50, сверка записи; длинные фильмы и большие наборы дорожек.
- [ ] Исправления по журналам реальных пользователей, более понятные диагностика и оценка времени.
- [ ] Цифровая подпись Windows-сборки.
- [ ] Калибровка автобитрейта на динамичных, тёмных, зернистых сценах и анимации; короткое сравнение исходника и результата, оценка метриками с учётом ограничений этих метрик.
- [ ] Управление кэшем из программы: занимаемое место, пригодные этапы, явная очистка выбранного проекта.
- [ ] Калибровка оценки PGS и резерва на длинных фильмах и больших наборах дорожек.

## Следующий этап — расширение авторинга

- [ ] DTS-HD и управление аудиодорожкой по умолчанию после отдельных испытаний.
- [ ] Настройка оформления субтитров и расширенная поддержка ASS/SSA.
- [ ] Обложки фильмов, дополнительные шаблоны коллекций и сезонов.
- [ ] Прямая замена меню готового многотитульного ISO без проекта и повторного авторинга потоков.
- [ ] Сохранение позиции между сеансами и более широкая навигация пультом.
- [ ] Расширение допустимых режимов видео без потери исходной частоты кадров.

## Отдельные направления

- [ ] Поддерживаемый и подписанный выпуск для macOS.
- [ ] Интегрированная запись с отчётом о сверке.
- [ ] UHD/HDR/4K — отдельный конвейер и отдельная программа испытаний.
- [ ] Оценить dav1d для программного декодирования AV1: сравнить скорость и совместимость с текущим FFmpeg; это не добавляет AV1 как формат обычного Blu-ray.
- [ ] Другие форматы носителей и библиотека медиаколлекций после стабилизации основного сценария.

Копирование защищённых дисков и обход DRM не входят в текущий продукт. [Границы продукта](PRODUCT_PLAN.md) · [Проверки 1.4.0](RELEASE_1.4.0.md).
