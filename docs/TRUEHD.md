# TrueHD / Atmos в DiskForge 1.4

Включено в DiskForge 1.4.0. Исправлено падение после кодирования при пользовательском фоне: встроенное изображение больше не принимается за путь Windows. Кэш видео и аудио остаётся совместимым.

В Windows tsMuxer запускается с `--no-asyncio`: последовательная запись исключает гонку закрытия файла с последним фоновым блоком. На полнометражном материале асинхронный режим вернул успех с усечённым M2TS; проверка CLPI и размера пакетов остановила сборку. Ключ кэша авторинга включает содержимое META, поэтому смена параметров требует повторного авторинга, но не кодирования. [Описание параметра tsMuxer](https://github.com/justdan96/tsMuxer/blob/master/docs/USAGE.md).

## Использование

1. Добавьте фильм, дождитесь анализа и откройте **Аудио**.
2. Отметьте дорожку **TrueHD** или **TrueHD / Atmos**. Выбор независим для каждой озвучки.
3. Оставьте **Автоматически** или выберите **Только копирование**. В обоих случаях TrueHD сохраняется побитно. Если проверки не пройдены, сборка остановится с объяснением.
4. Включите интерактивное меню и создайте ISO. На диске откройте **Аудио**, выберите озвучку стрелками и нажмите **OK**. Во время фильма меню открывается кнопкой Pop-up Menu.

Поддерживается TrueHD 48/96 кГц, до 8 каналов основной презентации, включая Atmos. Atmos распознаётся по профилю FFprobe. Если анализатор не распознал Atmos, весь поток всё равно сохраняется, но подпись остаётся TrueHD. E-AC-3 / Dolby Digital Plus с Atmos — другой формат, его сохранение не добавлено. TrueHD 192 кГц пока отклоняется.

Ручное **Преобразовать в AC-3** теряет lossless-качество и Atmos. Программа сама не выбирает такое преобразование для TrueHD. Даже при перекодировании изображения TrueHD можно сохранить.

## Авторинг и проверка

- FFmpeg извлекает TrueHD с `-c:a copy`, без `truehd_core`. Все исходные кадры и расширения Atmos сохраняются.
- Отдельно создаётся AC-3 640 кбит/с, 48 кГц, стерео или до 5.1 из той же озвучки. Создание этого совместимого слоя требует декодирования звука, но не меняет основной TrueHD. Даже если в MKV есть отдельная AC-3, программа не угадывает, совпадает ли она с выбранной озвучкой.
- AC-3 и неизменённые кадры TrueHD чередуются в одном потоке. `--new-audio-pes` позволяет различать их на одном PID. В меню это одна выбираемая дорожка, без дополнительного пункта для совместимого слоя.
- Проверяются временные метки контейнера, длительность, границы кадров, major sync, частота и объявленный пик TrueHD. Для миллисекундной шкалы MKV учитывается длительность кадра 1/1200 секунды.
- В бюджете транспорта консервативно резервируется до 18,64 Мбит/с на TrueHD плюс 640 кбит/с на AC-3. При нескольких TrueHD может потребоваться уменьшить видеобитрейт или выбрать меньше дорожек. Место под звук при перекодировании видео рассчитывается по фактическому объёму пакетов.
- После авторинга сверяются TrueHD-код MPLS, PID, порядок дорожек, каналы, частота и действия BD-J. SHA-256 закодированных данных TrueHD сравнивается между исходником и M2TS. Проверяются все байты, включая Atmos. AC-3 сравнивается со своим подготовленным файлом.
- Проверка смонтированного ISO подтверждает неизменность всех файлов. Отчёт `*.iso.verification.json` содержит поле `lossless_truehd`.
- Подготовленные TrueHD и AC-3 сохраняются в кэше возобновления. Повторная упаковка ISO не требует снова обрабатывать звук. Дополнительные файлы занимают место в `.diskforge-cache`.

## Испытания

Проверены короткие образцы TrueHD 5.1 / 48 кГц, TrueHD с Atmos 7.1 / 48 кГц и синтетический TrueHD stereo / 96 кГц. Прогон включает настоящий FFmpeg, tsMuxer, меню BD-J, ISO UDF 2.50, чтение файлов из ISO, повторную сборку из кэша и отказ при несовпадении контрольных сумм.

Физический плеер, пульт, HDMI bitstream и ресивер Atmos в этой сессии не проверены. Это не сертификация Blu-ray. Для Atmos нужны поддерживающие его плеер, режим вывода и аудиосистема; программное декодирование в PCM может давать звук без объектного Atmos.

Запуск разработчиком: `tools/truehd_media_test.py --ffmpeg <exe> --ffprobe <exe> --tsmuxer <exe> --work <каталог> --atmos <atmos.thd> --plain <TrueHD.raw>`.

Образцы: [FFmpeg FATE atmos.thd](https://fate-suite.ffmpeg.org/truehd/atmos.thd), [FFmpeg TrueHD.raw](https://samples.ffmpeg.org/A-codecs/TrueHD/TrueHD.raw). FATE-образец повторяется 19 раз полными кадрами без кодирования для короткого тестового фильма. Образцы и тестовые фильмы не включаются в приложение; их контрольные суммы сохраняются в отчёте.

Первоисточники: [параметры tsMuxer](https://github.com/justdan96/tsMuxer/blob/master/docs/USAGE.md), [AC-3 / TrueHD packetizer](https://github.com/justdan96/tsMuxer/blob/master/tsMuxer/ac3StreamReader.cpp), [major-sync header](https://github.com/justdan96/tsMuxer/blob/master/tsMuxer/mlpCodec.cpp), [FFmpeg: truehd_core удаляет Atmos](https://ffmpeg.org/ffmpeg-bitstream-filters.html#truehd_005fcore).
