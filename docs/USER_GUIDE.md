# Руководство DiscForge RU 1.1

[Все разделы](README.md) · [Аудио](AUDIO.md)

## 1. Подготовка

Добавьте видео кнопкой или перетащите файлы в окно. После анализа выберите фильм слева. Рекомендация учитывает видео, выбранные аудиодорожки и ёмкость BD25/BD50. «Авто» решает отдельно для каждого фильма. Принудительное «Без перекодирования» при несовместимом потоке остановится с объяснением, а не начнёт скрыто кодировать.

Поля FFmpeg, ffprobe и tsMuxer задают расположение инструментов; кнопки «…» открывают выбор исполняемого файла. В portable-сборке инструменты лежат в `tools`. «Сохранить ISO / BDMV в» выбирает папку результата; эта настройка доступна на всех вкладках. Для сборки нужны место под временные потоки, структуру и итоговый образ.

## 2. Аудио

Отметьте нужные дорожки для выбранного фильма. Отображаются язык, кодек, число каналов, частота и исходное название. По умолчанию отмечена первая. «Снять все» означает фильм без звука. Выбор сохраняется в проекте и восстанавливается после повторного анализа. [Правила преобразования](AUDIO.md).

В меню диска автоматически появится «Аудио». Выберите дорожку стрелками и OK. Во время фильма Pop-up Menu открывает этот раздел с паузой; выбор звука, Back или «Назад» возобновляют фильм. Исключённые галочками дорожки в меню не появятся.

## 3. Главы

Нажмите «Добавить главу», указав время `ЧЧ:ММ:СС`. Для правки выберите главу и измените тайминг. Можно автоматически расставить главы с заданным интервалом. Начальная глава `00:00:00` обязательна; время остальных должно быть меньше длительности фильма. Переход может быть привязан к ближайшему ключевому кадру.

## 4. Меню

Выберите «Полночь», «Графит» или «Кинотеатр». Можно загрузить своё фоновое изображение, выбрать заполнение/вписывание и затемнение. Язык переключает стандартные подписи между русским и английским. Пользовательские подписи сохраняются для каждого языка отдельно.

- Один щелчок по тексту или кнопке выделяет элемент. Перетащите его для перемещения.
- Двойной щелчок по надписи открывает ввод прямо в предпросмотре. Enter сохраняет, Esc отменяет ввод.
- Del удаляет выделенный текст или кнопку. Во время ввода Del удаляет символ. «Вернуть удалённый элемент» восстанавливает удаление, в том числе после открытия проекта.
- Маркеры на рамке меняют размер. У обычного текста вертикальное изменение рамки также меняет размер шрифта.
- В панели оформления доступны шрифт, начертание, размер и цвет текста; у кнопки дополнительно форма, заливка, прозрачность, обводка и цвет выделения.
- «Добавить кнопку» создаёт кнопку; выберите её действие — фильм, глава или страница. Нельзя собрать меню, из которого недоступен запуск фильма.
- Мягкие направляющие помогают выравниванию. Удерживайте Alt, чтобы временно отключить притяжение.

Необязательные подписи, включая верхний бренд, название, подзаголовок и подсказку снизу, можно удалить. Название проекта при этом сохраняется как метаданные.

«На весь экран · F11» открывает просмотр 16:9. Стрелки/Enter и кнопки снизу проверяют переходы. Esc/F11 возвращают редактор. Это просмотр меню, а воспроизведение фильма проверяется в VLC.

## 5. Создание и проверка ISO

Выберите ISO и нажмите «Создать Blu-ray». Журнал показывает этапы, рядом с прогрессом — прошедшее время и оценку оставшегося. В начале оценка может рассчитываться; она уточняется по скорости диска и кодирования. Отмена останавливает работу и убирает незавершённый результат.

После сборки нажмите «Проверить ISO в VLC». Нужен установленный VLC x64. Программа откроет образ как Blu-ray и передаст комплектную Java только дочернему процессу VLC, не изменяя системные переменные. Если запуск не удался, проверьте путь к VLC и целостность `runtime/java` рядом с EXE. Открытие диска как DVD (`dvd:///…`) не подходит.

Проверьте главное меню, запуск фильма, главы, выбор звука в разделе «Аудио», переключение во время фильма через Pop-up Menu и возврат в меню. После проверки готовый ISO можно записать через ImgBurn. Не выбирайте создание диска с данными из файла ISO: используйте запись **образа**.

## Изменение меню готового ISO

В «Запись ISO» выберите ISO DiscForge. «Загрузить меню из ISO» открывает настройки меню из образов 0.9 и новее. При загрузке старого ISO список аудио восстанавливается по его плейлисту. Отредактируйте и нажмите «Сохранить текущее меню в ISO…», указав новое имя.

«Исправить обводку в ISO…» работает и с прежними образами без проекта: сохраняет растровые страницы, фон, надписи и действия, заменяет выделение и движок меню. Для редактирования старых надписей откройте сохранённый проект либо создайте новое меню.

Видео/звук не перекодируются и не мультиплексируются повторно; M2TS, MPLS и CLPI копируются побайтно. Главы берутся из исходного ISO; их тайминги этим способом не меняются. Требуется место размером с ISO плюс небольшой запас. Создаётся новый образ, исходный сохраняется. Ранее подключённый пользователем образ не отключается автоматически.

## Проекты и перенос

Сохраните `.dfr.json`, чтобы продолжить работу. Фоновое изображение встраивается; фильмы хранятся как пути к исходным файлам. При переносе сохраните доступность этих путей или добавьте фильмы заново. Сохранённые проекты прежних версий открываются; для новых образов используется обновлённый рендерер. Существующие ISO сами по себе не изменяются.
