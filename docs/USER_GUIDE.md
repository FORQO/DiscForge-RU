# Руководство DiskForge 1.5.0

В 1.5.0 добавлены [бережное улучшение, сравнение до/после и тихий режим](VIDEO_ENHANCEMENT.md). В «Подготовке» улучшение включается отдельно для выбранного слева фильма и применяется к его пробам и полной сборке. Выбор сохраняется в проекте; новые фильмы добавляются без улучшения. Для копирования остальных совместимых фильмов используйте «Авто». Тихий режим общий для очереди.

В 1.5.0 также доступны: [автоматический выбор сложных сцен, пробное кодирование и общий битрейт по результатам сравнения качества](QUALITY_TRIAL.md). Откройте «Подготовка → Проба качества…»: по умолчанию проверяются три сцены, ручной выбор также доступен. По результатам проб битрейт применяется к выбранному фильму явной командой.

Если первичные пробы не подошли, включённый по умолчанию **«Автоподбор, если пробы не подошли»** проверит новые битрейты и уточнит подходящий вариант. Поиск ограничен восемью дополнительными раундами и допустимым потоком с учётом звука. Все готовые варианты можно просмотреть; применение к фильму остаётся отдельным действием.

После проб сохраните проект: результаты и история поиска теперь входят в `.dfr.json`. При повторном открытии «Проба качества…» проверит исходник и настройки и восстановит оценки без нового подбора. Сохраняются числовые результаты, а временные видео удаляются; [подробнее о проверке актуальности](QUALITY_TRIAL.md#сохранение-результатов-в-проекте).

В предпросмотре меню доступны «Вверх», «Вниз», «Влево» и «Вправо», в том числе на клавиатуре и в полном экране. Каждая стрелка выбирает ближайшую кнопку в указанной стороне по расстоянию между центрами, с учётом положения и размера. При равном расстоянии предпочтение получает кнопка ближе к оси направления, затем — первая по порядку на странице. Если в этой стороне кнопок нет, выделение остаётся на месте: циклического перехода нет. Точно совпадающие центры не различаются стрелками — разнесите такие кнопки в редакторе. Открытие выполняется по OK. Значок полного экрана расположен сразу после «Главное меню».

То же правило использует пульт в BD-J, включая каталог фильмов, главы, аудио и субтитры. Новое управление записывается при создании диска или обновлении меню ISO; уже записанные диски сами не изменяются.

В версии 1.4.0: [автоподбор и индивидуальные битрейты фильмов](BITRATE.md), [общий диск, кнопки фильмов, их главы, названия, порядок и шкала заполнения](COLLECTIONS.md), [TrueHD/Atmos без потерь](TRUEHD.md), [возобновление, NVDEC/CUDA и отчёты проверки](LOCAL_ENGINE.md).

Новые проекты используют тему «Кино · Янтарь»; в редакторе доступна также «Кино · Сапфир». Существующие проекты сохраняют своё оформление. Чтобы убрать логотип **с меню диска**, выберите его одним щелчком и нажмите Del; восстановление доступно через «Вернуть удалённый элемент». Для полного экрана нажмите значок четырёх углов рядом с кнопками пульта или F11.

## 1. Подготовка

Добавьте видео кнопкой или перетащите файлы в окно. После анализа выберите фильм слева. Рекомендация учитывает видео, выбранные аудиодорожки и ёмкость BD25/BD50. «Авто» решает отдельно для каждого фильма. Принудительное «Без перекодирования» при несовместимом потоке остановится с объяснением, а не начнёт скрыто кодировать.

Поля FFmpeg, ffprobe и tsMuxer задают расположение инструментов; кнопки «…» открывают выбор исполняемого файла. В portable-сборке инструменты лежат в `tools`. «Сохранить ISO / BDMV в» выбирает папку результата; эта настройка доступна на всех вкладках. Для сборки нужны место под временные потоки, структуру и итоговый образ.

В новых проектах включён общий диск и автоматический битрейт для каждого фильма. Таблица плана показывает обработку и размеры; ручные значения сохраняются в проекте. Шкала учитывает выбранные дорожки, меню и запас. Подробности: [коллекции](COLLECTIONS.md) и [битрейт](BITRATE.md).

## 2. Аудио

Отметьте нужные дорожки для выбранного фильма. Отображаются язык, кодек, число каналов, частота и исходное название. По умолчанию отмечена первая. «Снять все» означает фильм без звука. Выбор сохраняется в проекте и восстанавливается после повторного анализа. [Правила преобразования](AUDIO.md).

В меню диска автоматически появится «Аудио». Выберите дорожку стрелками и OK. Во время фильма Pop-up Menu открывает выбор аудио/субтитров с паузой; выбор звука, Back или «Назад» возобновляют фильм. Исключённые галочками дорожки в меню не появятся.

## 3. Субтитры

Отметьте встроенные дорожки или нажмите «Добавить SRT / SUP». Для выделенной строки можно изменить язык и название. По умолчанию дорожки не выбраны. В меню диска появится раздел «Субтитры» с пунктом «Выключить»; при запуске диска субтитры выключены. [Форматы и работа с пультом](SUBTITLES.md).

## 4. Главы

В списке «Главы фильма» выберите нужный фильм. Его название видно над главами и на странице выбора сцен в меню диска; изменения относятся только к нему.

При первом анализе программа автоматически импортирует готовые тайминги глав из MKV (а также из других контейнеров, если ffprobe обнаруживает в них главы). Эти отметки сразу появляются в списке и в меню диска. Тайминги сохраняются с точностью до миллисекунд; отметки сортируются, дубликаты объединяются, начало `00:00:00.000` добавляется при необходимости. О пропущенных ошибочных отметках программа сообщает в журнале. Более 999 глав автоматически не импортируются.

Вместе с таймингами импортируются названия сцен из тега `title`. Они видны в списке глав и на кнопках меню диска. Если названия нет, используется «Глава N». Названия приводятся к одной строке длиной до 120 символов; исходный текст не переводится автоматически.

Чтобы переименовать сцену, откройте страницу глав в предпросмотре меню и дважды нажмите на её подпись либо выберите кнопку и отредактируйте текст справа. «Сбросить подпись» возвращает название из MKV. Ручные подписи для русского и английского меню сохраняются отдельно.

Сохранённые главы проекта, названия и ручные изменения не заменяются при повторном анализе. У каждого фильма в очереди свой набор названий. При изменении тайминга подпись остаётся у своей сцены. Кнопка «Вернуть главы из файла» восстанавливает исходные тайминги и названия; ручные подписи сохранившихся глав имеют приоритет. Если готовых глав нет, добавьте их вручную или по интервалу.

Нажмите «Добавить главу», указав время `ЧЧ:ММ:СС.ммм`. Для правки выберите главу и измените тайминг. Можно автоматически расставить главы с заданным интервалом. Начальная глава `00:00:00` обязательна; время остальных должно быть меньше длительности фильма. Переход может быть привязан к ближайшему ключевому кадру.

## 5. Меню

Настройки меню находятся справа в прокручиваемой панели; её ширину можно менять разделителем. Предпросмотр занимает оставшееся пространство. При выборе элемента мышью панель показывает его подпись и оформление. F11 открывает полный экран; Esc возвращает в редактор.

Новые проекты используют «Кино · Янтарь» с прозрачным логотипом DiskForge; доступен «Кино · Сапфир». Сохранены прежние темы; иконка приложения содержит только крупный диск с искрой. Доступны также «Полночь» и «Кинотеатр». Тема интерфейса переключается отдельно в верхнем меню «Темы»: графитовая или синяя. Можно загрузить своё фоновое изображение, выбрать заполнение/вписывание и затемнение. Язык переключает стандартные подписи между русским и английским. Пользовательские подписи сохраняются для каждого языка отдельно.

- Один щелчок по тексту или кнопке выделяет элемент. Перетащите его для перемещения.
- Двойной щелчок по надписи открывает ввод прямо в предпросмотре. Enter сохраняет, Esc отменяет ввод.
- Del удаляет выделенный текст или кнопку. Во время ввода Del удаляет символ. «Вернуть удалённый элемент» восстанавливает удаление, в том числе после открытия проекта.
- Маркеры на рамке меняют размер. У обычного текста вертикальное изменение рамки также меняет размер шрифта.
- В панели оформления доступны шрифт, начертание, размер и цвет текста; у кнопки дополнительно форма, заливка, прозрачность, обводка и цвет выделения.
- «Добавить кнопку» создаёт кнопку; выберите её действие — фильм, глава или страница. Нельзя собрать меню, из которого недоступен запуск фильма.
- Мягкие направляющие помогают выравниванию. Удерживайте Alt, чтобы временно отключить притяжение.

Необязательные подписи, включая верхний бренд, название, подзаголовок и подсказку снизу, можно удалить. Название проекта при этом сохраняется как метаданные.

Значок четырёх углов или F11 открывает просмотр 16:9. Стрелки/Enter и кнопки снизу проверяют переходы. Esc/F11 возвращают редактор. Это просмотр меню, а воспроизведение фильма проверяется в VLC.

## 6. Создание и проверка ISO

Под временем сборки отображается мониторинг NVIDIA: температура GPU, загрузка GPU и отдельно кодировщика NVENC. Обновление — каждые 2 секунды, только во время сборки. Показания относятся ко всей видеокарте и включают другие запущенные программы; GPU и NVENC — разные показатели, их не нужно складывать. Температура относится к датчику GPU, не Hot Spot. При нескольких NVIDIA отображается каждая карта.

При температуре **85 °C и выше** появляется выделенное предупреждение, запись в журнале и один системный звуковой сигнал. Приложение также запрашивает привлечение внимания к своему окну; поведение зависит от ОС, а слышимость сигнала — от настроек системных звуков. Предупреждение снимается при **80 °C и ниже**; только после этого новое повышение снова подаст сигнал. 85 °C — порог предупреждения приложения, а не универсальный предел температуры всех GPU. Сборка автоматически не останавливается: при необходимости нажмите «Отмена». Если датчик пропал после предупреждения, последнее высокое значение остаётся с пометкой о недоступности датчика. После завершения сборки предупреждение явно относится к прошлым измерениям.

После завершения или отмены остаются последние показания с пометкой об остановке опроса. Недоступные значения показаны знаком «—». Мониторинг использует установленный драйвер NVIDIA и не изменяет частоты, питание или охлаждение. Отсутствие драйвера или ошибка опроса не останавливают сборку ISO. AMD/Intel в версии 1.4 не поддерживаются.

Выберите ISO и нажмите «Создать Blu-ray». Журнал показывает этапы, рядом с прогрессом — прошедшее время и оценку оставшегося. В начале оценка может рассчитываться; она уточняется по скорости диска и кодирования. Отмена останавливает работу и убирает незавершённый результат.

После сборки нажмите «Проверить ISO в VLC». Нужен установленный VLC x64. Программа откроет образ как Blu-ray и передаст комплектную Java только дочернему процессу VLC, не изменяя системные переменные. Если запуск не удался, проверьте путь к VLC и целостность `runtime/java` рядом с EXE. Открытие диска как DVD (`dvd:///…`) не подходит.

Проверьте главное меню, запуск фильма, главы, выбор звука в разделе «Аудио», переключение во время фильма через Pop-up Menu и возврат в меню. После проверки готовый ISO можно записать через ImgBurn. Не выбирайте создание диска с данными из файла ISO: используйте запись **образа**.

## Изменение меню готового ISO

В «Запись ISO» выберите ISO DiscForge. «Загрузить меню из ISO» открывает настройки меню из образов 0.9 и новее. При загрузке старого ISO списки аудио и имеющихся PGS-субтитров восстанавливаются по его плейлисту. Отредактируйте и нажмите «Сохранить текущее меню в ISO…», указав новое имя.

«Исправить обводку в ISO…» работает и с прежними образами без проекта: сохраняет растровые страницы, фон, надписи и действия, заменяет выделение и движок меню. Для редактирования старых надписей откройте сохранённый проект либо создайте новое меню.

Добавить отсутствующий файл субтитров через замену меню нельзя: для этого соберите ISO из фильма заново, используя копирование видео, если оно совместимо.

Видео/звук/PGS не перекодируются и не мультиплексируются повторно; M2TS, MPLS и CLPI копируются побайтно. Главы берутся из исходного ISO; их тайминги этим способом не меняются. Требуется место размером с ISO плюс небольшой запас. Создаётся новый образ, исходный сохраняется. Ранее подключённый пользователем образ не отключается автоматически.

## Проекты и перенос

Сохраните `.dfr.json`, чтобы продолжить работу. Фоновое изображение встраивается; фильмы и внешние субтитры хранятся как пути к исходным файлам. При переносе сохраните доступность этих путей или добавьте фильмы заново. Сохранённые проекты прежних версий открываются; для новых образов используется обновлённый рендерер. Существующие ISO сами по себе не изменяются.

## Открытие Blu-ray из Проводника

В меню DiskForge **Проводник → Добавить «Открыть Blu-ray в VLC»** установите команду для текущего пользователя. Затем нажмите правой кнопкой на диск или файл `.iso` и выберите **Открыть Blu-ray в VLC**. В Windows 11 команда может находиться в **Показать дополнительные параметры**.

DiskForge запускает отдельный VLC 64-bit в режиме Blu-ray с включённым меню и Java из своей папки `runtime/java`. Права администратора не нужны; стандартный пункт VLC и приложение по умолчанию не меняются. На диске должна присутствовать структура `BDMV/index.bdmv`.

Сохраняйте всю папку portable-программы вместе с Java. После перемещения папки повторите добавление команды из нового расположения. Для удаления используйте **Проводник → Удалить пункт из Проводника**. Эта команда доступна для накопителей; при выборе диска без Blu-ray программа покажет понятное сообщение.

## Прогресс проверки ISO

На последних процентах сборки появляется отдельная шкала проверки. В ней показаны этап, текущий файл, прочитанные гигабайты, скорость в МБ/с и примерное время до конца проверки. Итоговая проверка включает два прохода: сверку файлов внутри подключённого ISO и расчёт SHA-256 самого образа. Поэтому общий объём чтения примерно вдвое больше размера ISO. Это чтение данных, без повторного кодирования.

Во время подключения Windows шкала показывает ожидание. При паузе в чтении время помечается как рассчитываемое, вместо ложного обратного отсчёта. Проверка кэша и контрольных сумм BDMV показывается отдельно, с оценкой до конца соответствующего этапа. Общие 100% появляются только после успешного завершения сборки; отмена и ошибки остаются видны в журнале.
