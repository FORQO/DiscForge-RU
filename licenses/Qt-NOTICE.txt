The Windows 1.5.0 portable build uses unmodified Qt for Python / PySide6 Essentials
and Shiboken 6.12.0, dynamically loaded from _internal/PySide6 and _internal/shiboken6.

version 3. The LGPL and underlying GPL texts are provided in this directory.

Qt source: https://code.qt.io/cgit/qt/qtbase.git/tree/?h=v6.12.0
Qt for Python source: https://code.qt.io/cgit/pyside/pyside-setup.git/tree/?h=v6.12.0
Upstream source downloads: https://download.qt.io/official_releases/QtForPython/

Source installations on Python 3.11 use Qt for Python / PySide6 Essentials and
Shiboken 6.8.3 as specified in requirements.txt. Corresponding source:
https://code.qt.io/cgit/pyside/pyside-setup.git/tree/?h=v6.8.3
